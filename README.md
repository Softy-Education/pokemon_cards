# Pokémon Cards App 🎴✨

**Discover and explore hidden Pokémon gems with this interactive app!**

![App Preview](https://res.cloudinary.com/dj6kxvxqb/image/upload/v1736754514/pokemon_e5oa98.png)

## Features

- 🔍 **Search & Filter:** Quickly find your favorite Pokémon by name or type.
- 🎨 **Dynamic Cards:** Beautifully designed Pokémon cards with vibrant colors.
- 📱 **Responsive Design:** Fully functional on all devices, from desktop to mobile.
- 🌐 **API Integration:** Fetch live Pokémon data seamlessly.
